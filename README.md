# Simple Task Manager

## Description
Simple Task Manager merupakan aplikasi sederhana untuk membantu pengguna mengelola daftar tugas sehari-hari.

## Features
- Menambahkan tugas
- Mengedit tugas
- Menghapus tugas

## Technologies
- HTML
- CSS
- JavaScript

## Installation
1. Clone repository.
2. Buka folder project menggunakan VS Code.
3. Jalankan aplikasi melalui browser.

## Usage
Pengguna dapat menambahkan, mengedit, dan menghapus tugas melalui antarmuka aplikasi.
